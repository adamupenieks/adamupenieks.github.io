When does beta get priced?

The security market line is famously too flat. Drag the cutoff below to restrict the sample to days when institutional attention is concentrated on firm-specific news, and watch the line steepen toward the CAPM. Every number on this page is computed from the data behind Looking Away from the Market.

The security market line across attention states

Each day is classified by the residual from regressing aggregate institutional attention on attention to idiosyncratic news. A low residual means attention is anchored to firm-level news. The cutoff selects days whose residual is below the chosen trailing one-year percentile; 100 is the full sample.

Table rows are daily Fama–MacBeth regressions of next-day portfolio excess returns on prior-day rolling betas, averaged over the days in each state, with time-series t-statistics. The two "paper" rows use the exact state definitions from the paper; the "selected" row uses the slider's cutoff.

The market premium and where attention goes

The daily Fama–MacBeth market premium is noisy, so both series are shown as rolling averages, standardized. When the attention residual is low (attention anchored to firm-specific news), the estimated premium tends to be high.

How this page is built

Nothing on this page is computed on a server. A Python script (below) reads the daily portfolio returns, rolling betas, and the attention residual, and writes a small file of summary statistics: for each cutoff, the ten portfolio mean returns and the Fama–MacBeth slope, intercept, t-statistics, and R². The page reads that file and redraws when you move the slider. The underlying CRSP, Dow Jones, and Bloomberg data are licensed and are not distributed here.
